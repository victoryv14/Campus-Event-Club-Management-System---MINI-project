# Campus Event & Club Management System

A relational database mini project for managing student clubs and campus events at a university level.

## Project Intent & Scope
- **Outcome:** Complete, evaluation-ready Oracle Database 26ai project package (modular DDL, constraints, seed dataset, PL/SQL triggers & procedures, analytical queries, and Crow's Foot ER documentation).
- **Target Audience:** 3rd-semester DBMS course evaluators / lab faculty, and the 4-member student project team.
- **Why Now:** Abstract is finalized; transitioning from concept to implementation and documentation.
- **Success Criteria:** All SQL scripts execute cleanly in sequential order on Oracle 26ai, enforcing relational integrity across all operations (preventing venue overbooking, tracking membership roles and event attendance) with demonstrable complex queries and 3NF normalization.
- **Constraints:** Strictly Oracle Database 26ai; exactly the 7 entities specified in the abstract (`Student`, `Club`, `Event`, `Admin`, `Venue`, `Membership`, `Registration`), modeling roles and attendance inside bridge tables.
- **Out of Scope:** Frontend UI, backend application server code, or extra standalone tables beyond the 7 core entities.
